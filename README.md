# Нотный тренажёр

Тренажёр чтения нот с листа для цифрового пианино, подключённого по USB-MIDI.
Подробности замысла, приоритетов и архитектуры — в [CLAUDE.md](./CLAUDE.md).

## Статус

Этап 1 по плану: **каркас приложения**. Приложение ставится на главный экран планшета,
работает без сети и показывает экран «Жду пианино» со всеми состояниями связи.
MIDI-монитор этапа 0 живёт внутри как экран «Проверка пианино».

## Разработка

```bash
npm install
npm run dev
```

## Сборка и деплой

Сборка выкладывается на GitHub Pages автоматически при пуше в `main`
(см. `.github/workflows/deploy.yml`). Собрать локально:

```bash
npm run build
npm run preview
```

## Проверка на планшете

1. Открой опубликованный адрес (`https://<аккаунт>.github.io/piaono_app/`) в Chrome
   на Android-планшете — важно HTTPS, без него Web MIDI не работает.
2. Подключи пианино USB-кабелем к планшету (или через USB-хаб, если у планшета
   разъём USB-C).
3. Разреши доступ к MIDI, если браузер спросит.
4. Экран должен показать «Пианино на связи». Сыграй ноту — её имя (например, C4)
   сразу появится крупно по центру.
5. Кнопка «Проверка пианино» открывает список устройств и журнал всех нажатий.

## Установка на планшет и обновления

**Установка.** Открой адрес в Chrome, дождись полной загрузки, затем меню Chrome (⋮) →
«Установить приложение» (или «Добавить на главный экран»). На главном экране появится
иконка «Ноты» — дальше запускай с неё: приложение откроется в своём окне, без адресной
строки.

**Без интернета.** Первое открытие сохраняет приложение на планшете. После этого оно
запускается и работает с пианино и в авиарежиме — пианино подключено кабелем, сеть ему
не нужна.

**Обновления.** Новая версия скачивается сама, в фоне, и **никогда не перезагружает экран
посреди занятия**. Она включится при следующем запуске приложения. Если хочется сразу —
на главном экране появится кнопка «Обновить сейчас». Приложение проверяет, нет ли новой
версии, при запуске и каждый раз, когда возвращаешься в него (например, после сна
планшета), если есть сеть.

**Иконки.** Все PNG-иконки сделаны из `public/pwa-icon.svg`. Чтобы перерисовать: поправь
SVG и выполни `npx @vite-pwa/assets-generator@1` (настройки — в `pwa-assets.config.mjs`).
