# pwa-shell Specification

## Purpose

Делает тренажёр полноценным приложением на планшете: его можно установить на главный экран,
он запускается без сети и обновляется, не прерывая занятие.

## Requirements

### Requirement: Приложение устанавливается на главный экран
Приложение MUST соответствовать критериям установки Chrome на Android: иметь манифест
с полным и коротким названием, иконками 192×192 и 512×512 (включая маскируемую), стартовым
адресом и областью в пределах `/piaono_app/`, режимом отображения `standalone` и цветом фона,
совпадающим с «бумагой» интерфейса.

#### Scenario: Установка из Chrome
- **WHEN** владелец открывает опубликованный адрес в Chrome на Android-планшете и выбирает
  «Установить приложение» / «Добавить на главный экран»
- **THEN** на главном экране появляется иконка «Нотный тренажёр», и запуск с неё открывает
  приложение в отдельном окне без адресной строки браузера

#### Scenario: Заставка при запуске
- **WHEN** установленное приложение запускается с главного экрана
- **THEN** системная заставка показывает иконку и название на тёплом светлом фоне интерфейса,
  без белой или тёмной вспышки

### Requirement: Работа без сети
После первой успешной загрузки приложение MUST полностью открываться и работать без сетевого
соединения, включая все экраны и иконки. Работа с пианино MUST NOT зависеть от сети.

#### Scenario: Запуск в авиарежиме
- **WHEN** приложение уже открывалось хотя бы один раз, а планшет переведён в авиарежим
- **THEN** приложение открывается с главного экрана так же, как с сетью, и показывает
  состояние связи с пианино

#### Scenario: Игра без сети
- **WHEN** сети нет, а пианино подключено по USB
- **THEN** сыгранные ноты отображаются так же, как при наличии сети

### Requirement: Обновление без прерывания занятия
Новая версия приложения MUST загружаться в фоне и MUST NOT перезагружать открытый экран
без явного действия пользователя. Новая версия SHALL применяться при следующем запуске
приложения. Пока обновление ожидает, экран ожидания SHALL показывать ненавязчивую кнопку
«Обновить сейчас» (не модальное окно), которая применяет обновление немедленно.

#### Scenario: Вышла новая версия, приложение открыто
- **WHEN** на Pages опубликована новая версия, а приложение открыто на планшете
- **THEN** экран не перезагружается сам, а на экране ожидания появляется кнопка
  «Обновить сейчас»

#### Scenario: Применение обновления кнопкой
- **WHEN** пользователь нажимает «Обновить сейчас»
- **THEN** приложение перезапускается уже в новой версии, и связь с пианино
  восстанавливается автоматически

#### Scenario: Применение обновления при следующем запуске
- **WHEN** пользователь не нажимал кнопку, закрыл приложение и открыл снова
- **THEN** запускается новая версия

#### Scenario: Без сети обновление не мешает
- **WHEN** сети нет
- **THEN** приложение работает на последней сохранённой версии и не показывает ошибок
  об обновлении
