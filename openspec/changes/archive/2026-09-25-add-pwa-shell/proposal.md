# Proposal

## Why

Этап 0 подтвердил, что планшет стабильно видит пианино, в том числе после сна. Но сейчас это
просто веб-страница: без сети она не откроется, на главный экран как приложение не ставится,
а из состояний связи видны только четыре грубых варианта. Тренажёром будут пользоваться
каждый день — он должен запускаться одним касанием с главного экрана, работать без интернета
и всегда честно показывать, на связи ли пианино и что сделать, если нет. Это фундамент,
на котором дальше строятся упражнения (этап 1 плана в CLAUDE.md).

## What Changes

- Приложение становится устанавливаемым PWA: иконка на главном экране планшета, запуск
  в отдельном окне без адресной строки браузера, своё название и цвета.
- После первого открытия приложение полностью работает без сети (оболочка, стили, иконки
  хранятся на устройстве).
- Обновления приходят без участия пользователя и **никогда не перезагружают экран сами** —
  новая версия применяется при следующем запуске, а на экране ожидания появляется
  ненавязчивая кнопка «Обновить сейчас».
- Главный экран — «Жду пианино» — показывает каждое состояние связи отдельно, простыми словами
  и с подсказкой, что делать:
  - браузер не умеет MIDI;
  - доступ к MIDI запрещён (и как его вернуть);
  - подключаемся;
  - пианино не подключено (как подключить);
  - готово — пианино на связи, «сыграй любую ноту» с крупным именем сыгранной ноты;
  - связь потеряна — идёт автоматическое восстановление.
- MIDI-монитор из этапа 0 остаётся как диагностический экран «Проверка пианино»,
  доступный с главного экрана, — пригодится, если железо когда-нибудь закапризничает.
- Слой `midi/` начинает различать «доступ запрещён» и «браузер не поддерживает», а также
  «соединение потеряно» и «никогда не было подключено».

## Capabilities

### New Capabilities

- `pwa-shell`: установка приложения на устройство, работа без сети, политика обновлений.
- `connection-status`: экран состояний связи с пианино — что видит ученик в каждом
  состоянии и как состояния сменяют друг друга.

## Impact

- **Новая зависимость (dev):** `vite-plugin-pwa` — уже заявлена в стеке CLAUDE.md, это
  стандартный способ собрать манифест и service worker (Workbox) для Vite вместо ручного
  написания service worker'а.
- **Иконки:** генерируются один раз из исходного SVG и коммитятся как PNG; генератор
  постоянной зависимостью не становится.
- **Код:** `src/midi/` — расширение набора состояний; `src/ui/` — новый экран ожидания,
  монитор становится вторым экраном; `vite.config.ts`, `index.html` — подключение PWA.
- **Деплой:** тот же GitHub Actions → GitHub Pages, адрес не меняется.
- **Не затрагивает:** выбор устройства при нескольких MIDI-входах, упражнения, VexFlow,
  `localStorage` — это следующие этапы плана.
