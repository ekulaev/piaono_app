# Spec Delta

## ADDED Requirements

### Requirement: Возврат подсказок
Подтверждённый возврат подсказок (требование «Сброс с подтверждением» capability `progress-screen`)
MUST ставить уровень 3 и нулевой счёт обоим ключам и сохранять это на устройстве; статистика MUST
NOT меняться. (C-STF-7: OB-11, INV-2)

#### Scenario: Вернуть подсказки
- **WHEN** скрипичный на уровне 1, и подсказки возвращены
- **THEN** оба ключа на уровне 3, следующая последовательность — с якорем с названием и всеми подсказками
