# Spec Delta

## MODIFIED Requirements

### Requirement: Раскладка главного экрана с нотным станом
Главный экран MUST располагать сверху вниз: индикатор связи; строку подсказки о связи; зону
нотного стана; строку кнопок; зону клавиатуры. Если подсказке о связи не хватает места, MUST
прокручиваться только она. Нотный стан MUST занимать 90 % ширины зоны нотного стана и всю её
высоту вместе с местом для двух добавочных линий сверху и снизу; если зона ниже зоны клавиатуры,
нотный стан MUST уменьшаться так, чтобы поместиться целиком. Если в режиме «Последовательности»
действуют подсказки интервалов, верхнюю часть зоны MUST занимать полоса подсказок высотой не больше
четверти зоны, а нотный стан с местом для добавочных линий — остальную высоту. Нотный стан MUST
быть выровнен по центру зоны. Зона нотного стана MUST NOT прокручиваться. (C-STF-1: OB-18, OB-1,
NFR-2; C-STF-3: OB-10, NFR-3)

#### Scenario: Планшет в ландшафте
- **WHEN** приложение открыто на экране 1280×800
- **THEN** нотный стан виден целиком между строкой подсказки и кнопками, шириной 90 % зоны, выровнен по центру

#### Scenario: Телефон в ландшафте
- **WHEN** приложение открыто на экране 740×360
- **THEN** нотный стан уменьшен и помещается целиком, страница не прокручивается

#### Scenario: Полоса подсказок
- **WHEN** на экране 1280×800 идёт сессия «Последовательностей» с подсказками
- **THEN** над станом полоса подсказок не выше четверти зоны, стан с добавочными линиями помещается под ней целиком, страница не прокручивается
