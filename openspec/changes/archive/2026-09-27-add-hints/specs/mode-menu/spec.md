# Spec Delta

## MODIFIED Requirements

### Requirement: Кнопка активного режима
Справа от кнопки «Старт» главный экран MUST показывать кнопку с текстом «Режим: <название
активного режима>» с зоной касания не меньше 56×56 px. Кнопка MUST быть доступна в любом
состоянии приложения, в том числе во время упражнения, кроме времени, пока меню режимов открыто:
тогда кнопка MUST быть недоступна и выглядеть недоступной (пунктирная рамка, приглушённый текст),
чтобы меню не открывалось повторно. Сразу справа от кнопки режима MUST быть кнопка «?» с подсказкой
«Как играть: <активный режим>» (capability `hint`); во время упражнения её касание сначала
останавливает упражнение без итога. Нажатие «Старт» на главном экране MUST запускать упражнение
активного режима с его подтверждёнными настройками. (OB-1, OB-10; C-APP-2: OB-6, OB-10)

#### Scenario: Первый запуск
- **WHEN** приложение открыто впервые
- **THEN** справа от «Старт» кнопка «Режим: Разминка», справа от неё «?», а «Старт» запускает движущуюся ноту

#### Scenario: Меню уже открыто
- **WHEN** меню режимов открыто
- **THEN** кнопка «Режим: …» недоступна и выглядит недоступной

### Requirement: Экран режима
Выбор режима в списке MUST показывать экран режима: сверху кнопка «Назад» со стрелкой, заголовок
— название режима, рядом с ним кнопка «?» с подсказкой «Как играть: <режим>» (capability `hint`),
кнопка закрытия; ниже — настройки режима со значениями подтверждённых настроек (или значениями по
умолчанию, если режим ещё не подтверждался); внизу кнопки «Выбрать» и «Старт» с зоной касания не
меньше 56×56 px. Для режима без настроек вместо настроек MUST показываться текст «У этого режима нет
настроек». Если настройки не помещаются по высоте, MUST прокручиваться только область настроек;
верхняя строка и кнопки остаются видимыми. Элементы настроек MUST быть оформлены в стиле приложения с
контрастом не ниже 7:1. (OB-4, OB-8, NFR-1, NFR-2; C-APP-2: OB-10)

#### Scenario: Экран «Разминки»
- **WHEN** в списке выбрана «Разминка»
- **THEN** показаны «Назад», заголовок «Разминка», «?», текст «У этого режима нет настроек», кнопки «Выбрать» и «Старт»
