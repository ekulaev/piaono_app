# Spec Delta

## MODIFIED Requirements

### Requirement: Раскладка главного экрана с нотным станом
Главный экран MUST располагать сверху вниз: верхнюю панель (capability `app-settings`); зону
нотного стана; полосу нажатых нот (capability `note-echo`, только при включённом показе); строку кнопок; зону клавиатуры. Блока статуса связи и строки подсказки о связи на
главном экране MUST NOT быть — освободившаяся высота отдаётся зоне нотного стана. Нотный стан MUST
занимать 90 % ширины зоны нотного стана и всю её высоту вместе с местом для двух добавочных линий
сверху и снизу; если зона ниже зоны клавиатуры, нотный стан MUST уменьшаться так, чтобы поместиться
целиком. Если в режиме «Последовательности» действуют подсказки интервалов, верхнюю часть зоны MUST
занимать полоса подсказок высотой не больше четверти зоны, а нотный стан с местом для добавочных
линий — остальную высоту. Нотный стан MUST быть выровнен по центру зоны. Зона нотного стана MUST NOT
прокручиваться. В строке кнопок слева MUST быть слот кнопки по ходу упражнения: пока упражнение не
идёт, его место зарезервировано и пусто, так что «Старт» и «Режим» не сдвигаются при запуске.
(C-STF-1: OB-18, OB-1, NFR-2; C-STF-3: OB-10, NFR-3; C-APP-1: OB-6, OB-7, NFR-5; C-STF-8: OB-13)

#### Scenario: Планшет в ландшафте
- **WHEN** приложение открыто на экране 1280×800
- **THEN** нотный стан виден целиком между верхней панелью и кнопками, шириной 90 % зоны, выровнен по центру; зона стана выше, чем с блоком статуса

#### Scenario: Телефон в ландшафте
- **WHEN** приложение открыто на экране 740×360
- **THEN** нотный стан уменьшен и помещается целиком, страница не прокручивается

#### Scenario: Полоса подсказок
- **WHEN** на экране 1280×800 идёт сессия «Последовательностей» с подсказками
- **THEN** над станом полоса подсказок не выше четверти зоны, стан с добавочными линиями помещается под ней целиком, страница не прокручивается

#### Scenario: Полоса нажатых нот
- **WHEN** приложение открыто на экране 1280×800
- **THEN** сверху вниз: панель, зона стана, полоса нажатых нот постоянной высоты, строка кнопок, клавиатура; стан виден целиком, страница не прокручивается

#### Scenario: Показ выключен
- **WHEN** показ нажатых нот выключен в «Настройках»
- **THEN** полосы нет, зона стана выше на высоту полосы, страница не прокручивается

#### Scenario: Слот не сдвигает кнопки
- **WHEN** ученик нажимает «Старт» в «Последовательностях»
- **THEN** в слоте появляется «Пропустить», «Старт»/«Стоп» и «Режим» остаются на своих местах
