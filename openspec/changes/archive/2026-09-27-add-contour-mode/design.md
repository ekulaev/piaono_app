# Design

## Context

Мотивация — proposal.md, раздел Why. Требования — `specs/contour-mode` и изменения `mode-menu`,
`sequences-mode`, `practice-stats`.

Что из существующего переиспользуется и что мешает:

- **`engine/sequences/session.ts`.** Автомат сессии (`playing → finished → summary`, пропуск,
  отсчёт, «Повторить», статистика) подходит «Контуру» почти целиком. Мешает одно: `played()`
  сравнивает нажатие с записанными нотами шага. Одиночная нота засчитывается сразу, неполный
  аккорд закрывается в `closeGroup` по `tick`.
- **`engine/sequences/generate.ts`.** Ход интервалами от якоря, `MIN_INTERVAL = 2` — примы нет.
- **`engine/sequences/anchors.ts`.** `Direction = 'up' | 'down'`; `intervalBetween` для одинаковых
  нот отдаёт `{ size: 1, direction: 'up' }`.
- **`engine/stats`.**
  - Ключи интервалов проверяются шаблоном `^(up|down)[2-8]$`.
  - `hasProgress` смотрит только на ноты. Для «Контура» без нот это дало бы вечную «первую сессию»
    и вечное приглашение.
  - `StatsMode` и `PracticeStats` знают два режима.
- **`summarize` в `session.ts`.** Медленные места — по высоте (`{ pitch, averageMs }`).
- **Меню и настройки.** `ModeSettings = SequenceSettings | null`; `Settings.modeSettings` хранит
  только `sequences`.

## Goals / Non-Goals

**Goals:**

- Один автомат сессии для двух режимов. Отличие — вид проверки шага, одна ветка в `played`/`tick`.
- «Последовательности» после изменения ведут себя как раньше: прежние тесты не меняются, кроме
  формы `slowest`.
- Отклик «Контура» не позже 80 мс (окно 50 мс плюс кадр).

**Non-Goals:**

- «Шаг / скачок».
- Режим «Ритм» (этап 7б).
- Отдельная отрисовка: «Контур» рисуется тем же `SequenceStaff` без подсказок.

## Decisions

### D1. Направление «на месте» — `anchors.ts`

- `Direction = 'up' | 'down' | 'same'`.
- `intervalBetween(a, a)` → `{ size: 1, direction: 'same' }`; `moveBy(p, 1, 'same')` → `p`.
- В «Последовательностях» прима не генерируется, а подсказки считаются только между разными нотами,
  поэтому их поведение не меняется.

### D2. Генератор — параметр `allowRepeat`

- `buildSequence(settings, random, weights, { contour: true })`:
  - шаги одиночные при любом `notesPerStep`;
  - размеры интервала `1..max`, где размер 1 — единственное направление `same`.

  Первая нота по-прежнему отстоит от якоря; якорь в «Контуре» не показывается, но задаёт стартовую
  область диапазона.
- Взвешивание прежнее: `interval(1, 'same')` — вес перехода «на месте».
- Без `contour` всё как раньше: `MIN_INTERVAL = 2`.

**Альтернатива:** отдельный генератор контура. Отклонена: правила диапазона, интервалов и весов
те же, дублирование ради одного размера.

### D3. Вид проверки в автомате — `session.ts`

- В `Common` добавляется `check: 'exact' | 'contour'`. В `playing` — `reference: number | null`
  (точка отсчёта; `null` — первый шаг или шаг после пропуска).
- `played()` при `check === 'contour'` только копит группу: `hits` — все нажатые клавиши, ошибок
  сразу нет.
- `closeGroup` (по `tick` или следующему нажатию) при `contour`:
  - в группе больше одной клавиши → ошибка шага (`hadError`, `errorCount + 1`);
  - одна клавиша и `reference === null` → верно, `reference = клавиша`;
  - одна клавиша и направление `sign(key − reference)` совпадает с
    `sign(written[i] − written[i−1])` → верно, `reference = клавиша`, время реакции — от начала
    шага до первого нажатия группы;
  - иначе → ошибка, `reference` прежний.
- `skip` → `reference = null`. `playSequence` → `reference = null`. `wrongPitches` в «Контуре»
  всегда пуст.
- Цикл кадров уже идёт, пока открыта группа (`needsFrames`), поэтому оценка приходит на ближайшем
  кадре после 50 мс — до ~66 мс.
- `startSession(…, hints, stats, check = 'exact')`; `repeat` сохраняет `check`.

**Альтернатива:** засчитывать первое нажатие сразу, а второе в окне считать ошибкой задним числом.
Отклонена: шаг уже «осел» зелёным, откат выглядел бы как мигание, а это против CLAUDE.md §6.

### D4. Статистика — `engine/stats`

- `StatsMode` получает `contour`, `PracticeStats` — третий режим, `readPracticeStats` читает его
  независимо.
- Шаблон ключа интервала: `^(up|down)[2-8]$|^same1$`.
- `hasProgress(stats)` — есть ноты **или** интервалы. Это исправляет «вечную первую сессию» и
  приглашение для «Контура». Для двух старых режимов смысл не меняется: у них интервал без нот не
  бывает.
- `contourEvents(sequence, records)` — только события интервалов. Для шага `i ≥ 1`, если шаг `i − 1`
  не пропущен: `intervalBetween(written[i−1], written[i])`, исход шага `i`; время — только верно
  сразу.
- `improvements`: подпись `same1` → «=».

### D5. Итог — медленные места с подписью

- `SessionSummary.slowest` становится `{ label: string; averageMs: number }[]`:
  - «Последовательности» — имя ноты;
  - «Контур» — переход «↑3», «=».
- `summarize(sequences, history, hintsUsed, check)` при `contour` считает среднее время по переходам
  из тех же правил, что `contourEvents`.
- `SessionSummary` получает заголовок: «Самые медленные ноты» / «Медленные переходы» (короче — чтобы итог «Контура» влезал в один ряд).
  Пустой список: «Все шаги пропущены» / «Нет переходов, сыгранных сразу».

### D6. Режим, настройки, меню

- `MODES = [sequences, contour, warmup]`, `contour.hasSettings = true`.
- `Settings.modeSettings.contour: SequenceSettings`: тот же тип и `readSequenceSettings`.
  `notesPerStep` и `hints` у «Контура» не используются и не показываются.
- `ModeSettings` остаётся `SequenceSettings | null`.
- `SequenceSettingsForm` получает `variant: 'sequences' | 'contour'`: при `contour` нет «Нот в
  шаге» и «Подсказок».
- `App`:
  - `confirmedSettings('contour')` и `saveContourSettings`;
  - `startMode('contour')` → `sequences.start(settings, null, progress.stats.contour, 'contour')`;
  - сохранение статистики — в режим по `session.check`;
  - флажок «Переключать автоматически» — для активного режима «Последовательности» или «Контур»,
    меняет настройку активного режима;
  - приглашение — по `hasProgress(practice[activeMode])`: `activeMode` теперь включает `contour`.

## Risks / Trade-offs

- **[Задержка 50 мс на каждый шаг]** Ученик может почувствовать, что «Контур» отзывается чуть
  медленнее «Последовательностей». → В пределах «0–80 мс» (CLAUDE.md §6). Окно — одна константа.
  Если на планшете будет заметно, сузить окно только для «Контура».
- **[Прима как интервал «1»]** Меняется общий тип `Direction`. → Места использования перечислены
  в Context, прежние тесты «Последовательностей» остаются. Добавляются тесты на `same`.
- **[Уход за пределы клавиатуры]** С любой первой клавиши ученик может «уехать» вверх или вниз.
  → Направление проверяется по номеру клавиши, края клавиатуры (A0, C8) не мешают логике. На
  экранной клавиатуре видна область диапазона — центрирование прежнее.

## Migration Plan

- **Настройки.** `modeSettings.contour` отсутствует → значения по умолчанию.
- **Прогресс.** `stats.contour` отсутствует → пустая статистика. Ключ хранения прежний.
- **Откат** — revert PR. Старая версия игнорирует `contour` в настройках и прогрессе.
