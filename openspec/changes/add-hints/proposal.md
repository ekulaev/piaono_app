# Proposal

## Why

CLAUDE.md §10, этап 8в. Инструкции (как подключить пианино, как играть в режиме) загромождали бы
экран, но нужны под рукой. В 8а инструкции по связи стали временной строкой «что делать» в
«Настройках» (C-APP-1, Р-7). Нужен один универсальный элемент «?» для всего приложения. Источник
требований — C-APP-2 «Элемент „Подсказка“», редакция 1.

## What Changes

- **Элемент «Подсказка»:** кнопка «?» в круге (≥ 56 px), по умолчанию у правого края места; текст не
  виден.
- **Окно подсказки:** 80 % ширины, высота по содержимому, не больше 80 %; затемнение; шапка с
  заголовком и «Закрыть» видна всегда; вертикальная прокрутка содержимого с толстым ползунком,
  горизонтальной нет; закрытие — «Закрыть», Esc / системная «Назад», касание затемнения; фокус
  возвращается на «?». Поверх идущего упражнения не открывается.
- **Содержимое — данные:** `id → заголовок + блоки` (абзац, список шагов, изображение с подписью,
  нотный пример, ритмический пример); ссылка на несуществующую подсказку не проходит сборку.
- **Первые подсказки:**
  - строка «Пианино» в «Настройках» — «?» вместо строки «что делать», по состоянию связи;
  - экран каждого режима в меню режимов — «Как играть: <режим>»;
  - главный экран справа от кнопки «Режим: …» — та же подсказка активного режима, без захода в меню.
- План CLAUDE.md §10, этап 8в, — ссылка на спецификацию и change.

## Capabilities

### New Capabilities

- `hint`: элемент, окно, содержимое, первые подсказки.

### Modified Capabilities

- `app-settings`: «Строка „Пианино“» — «?» вместо строки «что делать».
- `connection-status`: где ученик узнаёт, что делать, — в подсказке строки «Пианино».
- `mode-menu`: «Экран режима» — «?» рядом с заголовком; «Кнопка активного режима» — «?» справа от неё.

## Impact

- **Новый код:** `src/ui/hints/` — кнопка, окно, типы блоков, содержимое подсказок, пример нот;
  значок «?».
- **Изменяется:** `ui/settings/SettingsScreen.tsx`, `ui/connectionTexts.ts` (строки «что делать»
  переезжают в содержимое подсказок), `ui/modes/ModeMenu.tsx`, CLAUDE.md §10.
- **Хранение не меняется. Новых зависимостей нет.**
