# Spec Delta

## MODIFIED Requirements

### Requirement: Меню режимов и список режимов
Нажатие кнопки режима MUST сразу, без анимации (не позднее 50 мс) показывать меню режимов у
правого края экрана поверх главного экрана. Меню MUST NOT перестраивать клавиатуру и MUST NOT менять размер и положение зоны нотного стана; на экране настроек «Разминки» в этой зоне MUST показываться предпросмотр диапазона (capability `warmup-settings`).
Список MUST содержать только доступные (реализованные) режимы в порядке «Последовательности»,
«Контур», «Ритм», «Разминка»; каждый — кнопка с зоной касания не меньше 56×56 px; активный режим MUST отличаться
заливкой и отметкой «выбран», а не только цветом. В правом верхнем углу меню MUST быть кнопка
закрытия со значком «×» и подписью «Закрыть». Ширина меню — `clamp(20rem, 40 %, 30rem)`, на
узком экране — вся ширина экрана. (OB-2, OB-14, NFR-3, NFR-4; C-STF-5: OB-1; C-STF-6: OB-1; C-STF-9: OB-9)

#### Scenario: Открыть меню
- **WHEN** упражнение не идёт и пользователь нажимает «Режим: Разминка»
- **THEN** у правого края сразу появляется меню со списком режимов, «Разминка» отмечена «выбран», и кнопкой «× Закрыть»; зона стана и клавиатура не сдвинулись

#### Scenario: Недоступный режим не показывается
- **WHEN** режим «Последовательности» ещё не реализован
- **THEN** в списке его нет ни в каком виде

#### Scenario: Три режима
- **WHEN** открыто меню режимов
- **THEN** «Последовательности», «Контур» и «Разминка» стоят в прежнем порядке относительно друг друга

#### Scenario: Четыре режима
- **WHEN** открыто меню режимов
- **THEN** в списке «Последовательности», «Контур», «Ритм», «Разминка» — в этом порядке

### Requirement: Экран режима
Выбор режима в списке MUST показывать экран режима: сверху кнопка «Назад» со стрелкой, заголовок
— название режима, рядом с ним кнопка «?» с подсказкой «Как играть: <режим>» (capability `hint`),
кнопка закрытия; ниже — настройки режима со значениями подтверждённых настроек (или значениями по
умолчанию, если режим ещё не подтверждался); внизу кнопки «Выбрать» и «Старт» с зоной касания не
меньше 56×56 px. Для режима без настроек вместо настроек MUST показываться текст «У этого режима нет
настроек». Если настройки не помещаются по высоте, MUST прокручиваться только область настроек;
верхняя строка и кнопки остаются видимыми. Элементы настроек MUST быть оформлены в стиле приложения с
контрастом не ниже 7:1. У режима «Разминка» настройки MUST быть (capability `warmup-settings`). (OB-4, OB-8, NFR-1, NFR-2; C-APP-2: OB-10; C-STF-9: OB-1)

#### Scenario: Экран «Разминки»
- **WHEN** в списке выбрана «Разминка»
- **THEN** показаны «Назад», заголовок «Разминка», «?», семь настроек (время, ключ, два диапазона, тональность, бекар, авто-сдвиг), кнопки «Выбрать» и «Старт»

#### Scenario: Режим без настроек
- **WHEN** открыт экран режима, у которого нет настроек
- **THEN** вместо настроек текст «У этого режима нет настроек»
