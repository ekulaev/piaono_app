# Spec Delta

## Purpose
Настройки режима «Разминка»: время движения ноты, ключ, диапазон нот для каждого ключа, тональность, бекар и авто-сдвиг клавиатуры; предпросмотр выбранного диапазона на нотном стане, предупреждение о диапазоне, не помещающемся на клавиатуру. Источник требований — C-STF-9 «Настройки режима „Разминка“», редакция 4; ссылки на его OB указаны в скобках.

## ADDED Requirements

### Requirement: Настройки «Разминки»
Экран режима «Разминка» в меню режимов MUST показывать семь настроек: «Время движения ноты» (ползунок с одной ручкой, 1–10 секунд, шаг 1 секунда, по умолчанию 5), «Ключ» (переключатель с одним выбором: «Скрипичный», «Басовый», «Оба»; по умолчанию «Оба»), «Диапазон скрипичного ключа» (ползунок с двумя ручками, от `E3` до `F6`, по умолчанию `G3`–`D6`), «Диапазон басового ключа» (ползунок с двумя ручками, от `G1` до `A4`, по умолчанию `B1`–`F4`), «Тональность» (выпадающий список, по умолчанию «До мажор»), «Использовать бекар» (флажок, по умолчанию выключен), «Авто-сдвиг клавиатуры» (флажок, по умолчанию выключен). Значения MUST быть подтверждёнными настройками режима, а если режим ещё не подтверждался — значениями по умолчанию. Октавы MUST считаться в научной нотации (`C4` — середина клавиатуры). (C-STF-9: OB-1, Р-1, Р-6)

#### Scenario: Первое открытие
- **WHEN** настройки «Разминки» ни разу не подтверждались и открыт экран режима
- **THEN** время 5 с, ключ «Оба», диапазоны `G3`–`D6` и `B1`–`F4`, «До мажор», оба флажка выключены

#### Scenario: Подтверждённые значения
- **WHEN** ученик подтвердил время 8 с и ключ «Басовый», затем снова открыл экран режима
- **THEN** показаны 8 с и «Басовый»

### Requirement: Ползунки
Ползунок с одной ручкой MUST выбирать одно значение из ряда целыми шагами, ручка MUST NOT вставать между значениями, рядом MUST крупно показываться выбранное значение («5 с»). Ползунок с двумя ручками MUST выбирать нижнюю и верхнюю границы на одной шкале с шагом в одну ноту (одну ступень), верхняя ручка MUST NOT быть ниже нижней, между ручками MUST оставаться не меньше двух нот, подписи обеих границ MUST показывать имя ноты как на карточке нажатой ноты (слог, буква, октава) без знака тональности и число нот в диапазоне. Зона касания ручки MUST быть не меньше 56×56 px, контраст не ниже 7:1, фокус виден, управление с клавиатуры устройства: стрелки — шаг, Home/End — границы. Отклик на движение ручки MUST быть виден не позднее чем через 50 мс. (C-STF-9: OB-2, OB-4, OB-5, INV-1, NFR-1, NFR-2, Р-11, Р-21)

#### Scenario: Время движения
- **WHEN** ученик ведёт ручку «Времени движения ноты» от 5 до 8
- **THEN** значение проходит 6, 7, 8 целыми секундами, рядом написано «8 с»

#### Scenario: Ручки не сходятся
- **WHEN** ученик тянет верхнюю ручку скрипичного диапазона вниз до нижней
- **THEN** верхняя останавливается на ноту выше нижней, в диапазоне остаётся не меньше двух нот

#### Scenario: Подписи границ
- **WHEN** скрипичный диапазон — `E3`–`F6`
- **THEN** подписи «Mi · E3» и «Fa · F6», рядом число нот 23

### Requirement: Выбор ключа и диапазонов
Ползунок диапазона ключа MUST показываться только для ключа, выбранного в «Ключе» («Оба» — для обоих). Границы невыбранного ключа MUST сохраняться и возвращаться при повторном выборе. (C-STF-9: OB-3, OB-6, Р-12)

#### Scenario: Один ключ
- **WHEN** в «Ключе» выбран «Басовый»
- **THEN** виден ползунок басового диапазона, скрипичного нет; при возврате к «Оба» скрипичный показан с прежними границами

### Requirement: Тональность и бекар
Выпадающий список «Тональность» MUST содержать 30 строк (15 наборов знаков при ключе, в каждом мажор, затем минор), отсортированных по числу знаков: без знаков, затем от одного до семи диезов, затем от одного до семи бемолей; каждая строка называет тональность и показывает число знаков («Соль мажор · 1♯»). Список MUST повторять вид и поведение списка языков: закрывается выбором, касанием вне списка и Esc, выбор применяется сразу, строка не меньше 56×56 px. Мажор и минор с одинаковыми знаками MUST давать одни и те же ноты. Флажок «Использовать бекар» MUST быть доступен только для тональности со знаками при ключе; в тональности без знаков MUST показываться неактивным (пунктирная рамка, приглушённый текст) с короткой пометкой, его значение MUST сохраняться. (C-STF-9: OB-7, OB-8, Р-2, Р-13, Р-22; приложение Г)

#### Scenario: Порядок списка
- **WHEN** открыт список «Тональность»
- **THEN** первая строка «До мажор», затем «ля минор», затем «Соль мажор · 1♯», «ми минор · 1♯» и так до «до♭ мажор · 7♭» и «ля♭ минор · 7♭»; всего 30 строк

#### Scenario: Бекар без знаков
- **WHEN** выбрана «До мажор»
- **THEN** флажок «Использовать бекар» неактивен и подписан пометкой; при выборе «Соль мажор» он становится доступным с прежним значением

### Requirement: Предпросмотр на нотном стане
Пока открыт экран настроек «Разминки», в зоне нотного стана главного экрана MUST показываться предпросмотр: станы выбранных ключей (при «Оба» — два друг над другом, скрипичный сверху; при одном ключе — один на всю высоту зоны). Каждый стан MUST иметь ключ, знаки выбранной тональности и все ноты допустимого диапазона этого ключа подряд слева направо, по возрастанию, по одной на ступень, с повышением и понижением по знакам тональности (знак у самой ноты не рисуется, бекар не показывается). Стан MUST оставаться шириной 95 % зоны; все ноты MUST располагаться только в части зоны, не закрытой меню, с равными промежутками и MUST NOT наползать друг на друга. Выбранный диапазон MUST быть подсвечен формой и цветом: ноты диапазона — заполненные головки акцентного цвета на подложке-полосе, ноты вне диапазона — пустые (контурные) головки цвета ноты; контраст всех нот не ниже 7:1. Подсветка MUST следовать за ручкой в процессе движения, не позднее чем через 50 мс; смена тональности MUST менять знаки и ноты за то же время. После закрытия меню предпросмотр MUST исчезать. (C-STF-9: OB-9, OB-10, OB-11, NFR-2, NFR-3, Р-8, Р-18)

#### Scenario: Оба ключа
- **WHEN** в «Ключе» выбран «Оба» на экране 1280×800
- **THEN** в зоне стана два стана друг над другом, на каждом по 23 ноты в видимой части зоны слева от меню, ни одна нота не под меню

#### Scenario: Подсветка за ручкой
- **WHEN** ученик двигает нижнюю ручку скрипичного диапазона на одну ноту вверх
- **THEN** нижняя нота диапазона на стане сразу становится пустой, подложка сдвигается на ноту

#### Scenario: Знаки тональности
- **WHEN** выбрана «Ре мажор»
- **THEN** на обоих станах после ключа `F♯` и `C♯`, ноты F и C нарисованы повышенными без знака у ноты

#### Scenario: Закрытие меню
- **WHEN** меню закрыто
- **THEN** предпросмотра нет, зона стана — как до открытия меню

### Requirement: Авто-сдвиг клавиатуры
При включённом «Авто-сдвиге клавиатуры» упражнение «Разминки» MUST сдвигать видимую часть экранной клавиатуры так, чтобы самая низкая нота диапазона ключа ноты была крайней слева видимой клавишей: при выборе одного ключа — при нажатии «Старт»; при «Оба» — при появлении ноты, ключ которой отличается от ключа предыдущей ноты (первая нота сессии считается сменой). Новая нота MUST появляться уже при сдвинутой клавиатуре. Авто-сдвиг MUST NOT срабатывать до «Старт», при ноте того же ключа, после ручной прокрутки и при выключенной настройке. Если нота не может стать крайней слева из-за правого края клавиатуры, видимая часть MUST прижиматься к краю; если видны все 88 клавиш, клавиатура MUST оставаться как есть. Сдвиг MUST происходить сразу, без анимации, не позднее чем через 50 мс после появления ноты. (C-STF-9: OB-22, OB-23, OB-24, OB-25, OB-26, Р-15, Р-16, Р-24)

#### Scenario: Один ключ
- **WHEN** авто-сдвиг включён, ключ «Басовый», диапазон `B1`–`F4`, ученик нажимает «Старт»
- **THEN** крайняя слева видимая клавиша — B1, первая нота уже на стане

#### Scenario: Смена ключа при «Оба»
- **WHEN** авто-сдвиг включён, ключ «Оба», после ноты в скрипичном ключе появляется нота в басовом
- **THEN** клавиатура сдвигается: крайняя слева — нижняя нота басового диапазона; следующая нота басового ключа клавиатуру не двигает

#### Scenario: Ручная прокрутка
- **WHEN** ученик прокрутил клавиатуру кнопками и появилась нота того же ключа
- **THEN** клавиатура остаётся где была

#### Scenario: Настройка выключена
- **WHEN** авто-сдвиг выключен
- **THEN** клавиатура сама не двигается никогда

### Requirement: Предупреждение о диапазоне
Если число нот выбранного диапазона ключа больше вместимости клавиатуры (числа полностью видимых белых клавиш при текущем размере рабочей области), рядом с ползунком этого диапазона MUST показываться отметка-предупреждение: значок и короткая подпись («Не помещается на клавиатуре: нужна прокрутка»), различимые формой и цветом. Когда диапазон помещается, отметки MUST NOT быть. Диапазоны ключей MUST проверяться каждый сам по себе, для невыбранного ключа отметки MUST NOT быть. Отметка MUST появляться и исчезать не позднее чем через 50 мс при движении ручки и при смене размера рабочей области или ориентации. Отметка MUST только предупреждать: диапазон сохраняется и запускается как выбран. (C-STF-9: OB-27, OB-28, Р-17)

#### Scenario: Диапазон шире клавиатуры
- **WHEN** на экране, где видно 20 белых клавиш, выбран скрипичный диапазон из 23 нот
- **THEN** рядом с ползунком скрипичного диапазона отметка с подписью; у басового диапазона из 10 нот отметки нет

#### Scenario: Поворот экрана
- **WHEN** вместимость клавиатуры выросла с 20 до 30 клавиш
- **THEN** отметка исчезает сразу

### Requirement: Сохранение и обратная совместимость
Подтверждённые настройки «Разминки» MUST сохраняться между запусками в `piaono.settings.v1` без смены версии ключа; закрытие меню без подтверждения MUST NOT сохранять изменения. Настройки MUST NOT меняться во время упражнения. Отсутствующее поле MUST читаться как значение по умолчанию; повреждённое или вне допустимых границ значение одной настройки MUST заменяться значением по умолчанию только для неё, остальные настройки и прогресс MUST сохраняться, ошибка на экране MUST NOT показываться. При значениях по умолчанию распределение пар «нота + ключ» MUST совпадать с прежним: белые клавиши B1–D6 равновероятны, нота общей зоны G3–F4 делится между ключами пополам. (C-STF-9: OB-18, OB-19, приёмочные гейты)

#### Scenario: Старые данные
- **WHEN** на устройстве сохранены данные без настроек «Разминки»
- **THEN** «Разминка» идёт как раньше: оба ключа, 5 с, прежние диапазоны, без знаков и бекара; прогресс цел

#### Scenario: Повреждённое значение
- **WHEN** в сохранённых настройках диапазон басового ключа записан вне допустимых границ
- **THEN** басовый диапазон `B1`–`F4`, остальные настройки «Разминки» прежние

#### Scenario: Распределение по умолчанию
- **WHEN** при настройках по умолчанию выбрано 100 000 нот без статистики
- **THEN** каждая белая клавиша B1–D6 встречается с одной частотой (допуск 5 %), в общей зоне G3–F4 скрипичный и басовый ключ — поровну

### Requirement: Компактный экран
Если окно компактное (экранной клавиатуры нет), флажок «Авто-сдвиг клавиатуры» и предупреждение о диапазоне MUST NOT показываться, авто-сдвига MUST NOT быть; сохранённое значение флажка MUST сохраняться и снова действовать на обычном экране. Остальные настройки MUST работать. (C-STF-9: OB-29, Р-20)

#### Scenario: Нет клавиатуры
- **WHEN** окно компактное и открыты настройки «Разминки»
- **THEN** флажка авто-сдвига и отметок о диапазоне нет, остальные настройки доступны
