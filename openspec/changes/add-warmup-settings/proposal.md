# Proposal

## Why

«Разминка» — единственный режим без настроек: время хода ноты (5 с), диапазоны нот (скрипичный G3–D6, басовый B1–F4), «оба ключа случайно» и только белые клавиши зашиты в код. Ученик не может ни замедлить ноту, ни тренировать один ключ, ни выбрать участок диапазона, ни читать ноты со знаками при ключе. Источник требований — C-STF-9 «Настройки режима „Разминка“» (`PSD/specifications/M-STF/C-STF-9 Настройки режима «Разминка».md`), статус `ready`, редакция 4.

## What Changes

- **Экран настроек «Разминки»** в меню режимов: ползунок «Время движения ноты» (1–10 с, шаг 1 с, по умолчанию 5), выбор «Ключ» (Скрипичный / Басовый / Оба, по умолчанию Оба), два ползунка диапазона с двумя ручками (скрипичный `E3`–`F6`, по умолчанию `G3`–`D6`; басовый `G1`–`A4`, по умолчанию `B1`–`F4`; шаг — одна нота, не меньше двух нот), выпадающий список «Тональность» (30 строк: 15 наборов знаков × мажор/минор, по возрастанию числа знаков, сначала диезы, потом бемоли; по умолчанию До мажор), флажки «Использовать бекар» и «Авто-сдвиг клавиатуры» (оба по умолчанию выключены).
- **Предпросмотр в рабочей области**: пока открыты настройки, в зоне нотного стана — станы выбранных ключей (при «Оба» два друг над другом) со всеми нотами допустимого диапазона и знаками тональности; выбранный диапазон подсвечен формой и цветом в реальном времени вслед за ручкой; ноты умещаются в части зоны, не закрытой меню.
- **Упражнение по настройкам**: время хода, ключ, диапазоны, знаки при ключе на стане, нота проверяется по звучащей высоте с учётом знаков; при включённом бекаре нота со знаком при ключе может прийти с бекаром (случайно, трудные чаще). Чёрные клавиши теперь возможны, но только как ноты тональности или после бекара.
- **Авто-сдвиг клавиатуры**: на «Старт» (один ключ) и при появлении ноты другого ключа («Оба») видимая часть клавиатуры ставит самую низкую ноту диапазона этого ключа крайней слева.
- **Предупреждение о диапазоне**: рядом с ползунком отметка (значок и подпись), если диапазон шире вместимости клавиатуры.
- **Нотный стан на 95 % ширины зоны** (было 90 %) для всех режимов.
- **Новые общие элементы управления** в `ui/controls`: ползунок с одной ручкой, ползунок с двумя ручками, выпадающий список (на основе списка языков).
- **Данные**: новые поля в `piaono.settings.v1` без смены версии; старые данные читаются, «Разминка» идёт как прежде.
- **Не входит:** предпросмотр и настройки на компактном экране (телефон) — отдельная задача (`Б-STF-5`, `C-APP-5`); хроматика, гармонический минор; тональности в других режимах.

## Capabilities

### New Capabilities

- `warmup-settings`: настройки «Разминки», элементы «ползунок» и «выпадающий список», предпросмотр диапазона, тональность и бекар, авто-сдвиг клавиатуры, предупреждение о диапазоне, хранение и обратная совместимость, поведение на компактном экране.

### Modified Capabilities

- `staff-exercise`: «Раскладка главного экрана с нотным станом» (95 %, три добавочные линии), «Вид нотного стана» (знаки при ключе, бекар), «Выбор ноты и ключа» (по настройкам), «Движение ноты» (время из настройки).
- `mode-menu`: «Меню режимов и список режимов» (на экране настроек «Разминки» в зоне стана предпросмотр), «Экран режима» (у «Разминки» теперь есть настройки).
- `localization`: «Что переводится» (названия тональностей и подписи настроек переводятся).
- `piano-keyboard`: новые требования — программный сдвиг видимой части и вместимость клавиатуры.
- `practice-stats`: новое требование — ноты со знаками в статистике и их названия.

## Impact

- **Новый код:** `engine/warmup/` (настройки и чтение с устройства, 30 тональностей, набор нот и выбор), чистые функции с тестами; `ui/warmup/` (форма настроек, предпросмотр); элементы `Slider`, `RangeSlider`, `Dropdown` в `ui/controls/`.
- **Меняется:** `engine/staff/exercise.ts` и `pickNote.ts` (время и набор нот из настроек; нота со ступенью и знаком), `ui/staff/staffDrawing.ts` и `staffHooks.ts` (95 %, знаки при ключе, бекар), `ui/keyboard/Keyboard.tsx` (выравнивание фокуса по левому краю, вместимость наружу), `ui/modes/ModeMenu.tsx`, `ui/App.tsx`, `engine/modes/modes.ts` и `modeMenu.ts` (у «Разминки» есть настройки), `storage/settings.ts` (поле `modeSettings.warmup`), статистика и итог «Разминки» (названия нот со знаками), `i18n/locales/ru.ts` и `en.ts`, таблица общих механизмов в `CLAUDE.md` §4.
- **Зависимости:** новых нет. VexFlow уже умеет знаки при ключе и бекар.
- **Риски:** это самая большая правка «Разминки» — владелец занимается ею каждый день. Защита: значения по умолчанию воспроизводят прежнее поведение (тест на совпадение распределения), данные читаются без миграции, а MIDI-слой не затрагивается.
- **Как проверить на планшете с пианино:** открыть меню → «Разминка»: без изменений нажать «Старт» — всё как раньше; затем поставить время 8 с и ключ «Басовый» — нота идёт медленнее, только басовый; двигать ручки диапазона и смотреть, как подсвечиваются ноты на стане; выбрать «Соль мажор» — на стане знак при ключе, на F нужно играть F♯; включить бекар — иногда нота с бекаром и играть нужно F; включить авто-сдвиг — по «Старт» клавиатура ставит нижнюю ноту диапазона слева, при «Оба» сдвигается при смене ключа; растянуть диапазон шире клавиатуры — рядом с ползунком предупреждение; перезапустить приложение — настройки на месте.
