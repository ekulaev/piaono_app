# Proposal

Источник требований — `PSD/specifications/M-APP/C-APP-4 Резервная копия прогресса.md`.

## Why

Настройки и накопленный прогресс живут только в `localStorage` планшета. Смена устройства, очистка
данных браузера или переезд приложения на новый адрес (волна 0, `M-LAUNCH`) стирают всё без
возврата. Резервная копия в файл — единственная защита, а группы «Настроек» (`C-APP-6`) уже
оставили ей место.

## What Changes

- В баре «Настроек» новая группа «Копия» (Backup) между «Клавиатурой» и «Версией», со своим значком.
- В группе две строки: «Сделать копию» — кнопка «Сохранить» и «?»; «Загрузить копию» — кнопка
  «Выбрать файл». Под строками — итог последнего действия со значком (галочка или предупреждение).
- «Сохранить» создаёт файл `piaono-backup-ГГГГ-ММ-ДД-ЧЧ-ММ.json`: метка приложения, версия формата,
  дата копии, все настройки и весь прогресс. Android и компьютеры скачивают файл, iPhone и iPad
  открывают окно «Поделиться».
- «Выбрать файл» открывает системное окно выбора файлов JSON. Оболочка файла проверяется: не JSON,
  нет метки, незнакомая версия, нет даты, больше 1 МБ — «Копия повреждена», данные не меняются.
- Для годной копии — диалог «Да / Нет» с датой копии. «Да» заменяет настройки и прогресс вместе;
  повреждённые поля внутри получают значения по умолчанию, как при обычном чтении. Приложение не
  перезапускается и остаётся на группе «Копия»; всё сразу работает на данных копии.
- Сбой сохранения или записи — понятный итог; при сбое записи данные на устройстве прежние.
- Подсказка «?» про копию, тексты на русском и английском.

Поведение остальных настроек, режимов и MIDI не меняется. Формат `piaono.settings.v1` и
`piaono.progress.v1` не меняется.

## Capabilities

### New Capabilities
- `progress-backup`: копия настроек и прогресса в файл и восстановление из файла — содержимое и имя
  файла, сохранение на разных системах, проверка оболочки, диалог с датой, замена данных, итоги и
  сбои.

### Modified Capabilities
- `app-settings`: четвёртая группа «Копия» в составе экрана «Настройки» и в баре групп; значок
  группы.

## Impact

- `src/storage/backup.ts` (новый) — сборка копии, проверка оболочки, замена обеих частей вместе.
- `src/storage/settings.ts`, `src/storage/progress.ts` — чтение из готового объекта выносится в
  отдельные функции (`loadSettings` / `loadProgress` ими пользуются); поведение прежнее.
- `src/ui/settings/` — группа «Копия», строки, итог; сохранение файла и выбор файла.
- `src/ui/App.tsx` — после восстановления дерево приложения пересоздаётся на новых данных.
- `src/ui/settings/groups.ts`, `src/ui/icons/Icons.tsx` — четвёртая группа и значок.
- `src/ui/hints/hints.ts` — подсказка про копию.
- `src/i18n/format.ts`, `src/i18n/locales/ru.ts`, `en.ts` — дата со временем, тексты.
- Новых зависимостей нет. Сетевых запросов нет.

Проверка на планшете с пианино: «Настройки» → «Копия» → «Сохранить» — файл в «Загрузках», итог с
именем файла. На «Прогрессе» сбросить статистику одного режима. «Выбрать файл» → этот файл →
диалог с датой и временем копии → «Нет» — ничего не изменилось; ещё раз → «Да» — итог
«Прогресс восстановлен…», статистика вернулась, пианино на связи и играет. Выбрать любой другой
файл (например, фото) — «Копия повреждена», данные прежние.
