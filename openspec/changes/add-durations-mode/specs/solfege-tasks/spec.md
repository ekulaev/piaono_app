## MODIFIED Requirements

### Requirement: Легенда над клавишами
В задании с ответом-значением над клавишами из таблицы режима MUST стоять легенда — короткое значение на языке приложения, а в режиме, где так задано, ещё и значок, нарисованный нотным шрифтом, не мельче 18 px, контраст не ниже 7:1, над каждой октавой видимой части; легенда MUST сдвигаться вместе с клавиатурой и MUST NOT перекрывать ноты на стане. В задании с ответом-нотой легенды MUST NOT быть. (C-SOL-1: OB-14; C-SOL-3: OB-7, NFR-4)

#### Scenario: Легенда видна
- **WHEN** показано задание «Узнай интервал» на планшете
- **THEN** над до♯ видно «м2», над фа♯ — «тр», над каждой видимой октавой

#### Scenario: Ответ-нота
- **WHEN** показано задание «Сыграй интервал»
- **THEN** легенды нет

#### Scenario: Легенда со значком
- **WHEN** показано задание «Длительностей»
- **THEN** над «ре» значок половинной ноты и «1/2»; легенда «Интервалов» по-прежнему только текстом

### Requirement: Данные режимов сольфеджио
Настройки режимов сольфеджио MUST храниться в `piaono.settings.v1`, статистика — в `piaono.progress.v1` новыми полями — у каждого режима свои настройки и своя статистика, — без смены версии ключей. Отсутствующие поля MUST давать значения по умолчанию; повреждённая часть режима MUST заменяться значением по умолчанию только для этой части, без ошибки на экране. (C-SOL-1: NFR-3; C-SOL-3)

#### Scenario: Старые данные
- **WHEN** на устройстве записи до этого change
- **THEN** все прежние настройки и статистика на месте, «Интервалы» с настройками по умолчанию и без статистики

#### Scenario: Повреждённая статистика «Интервалов»
- **WHEN** запись статистики «Интервалов» повреждена
- **THEN** у «Интервалов» пустая статистика, у остальных режимов прежняя

#### Scenario: Данные «Длительностей»
- **WHEN** на устройстве записи до этого change
- **THEN** «Длительности» с настройками по умолчанию и без статистики; настройки и статистика «Интервалов» на месте
