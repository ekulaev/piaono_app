# Proposal

## Why

Сейчас в тренажёре только «Разминка»: одна нота, которую нужно успеть сыграть. Главная идея
проекта — читать **в потоке**, последовательностями, в своём темпе (CLAUDE.md §1, §7). Это этап 4
плана: основной цикл «показать последовательность → играть → проверка → обратная связь → итог
сессии». Источник требований — C-STF-2 «Режим „Последовательности“», редакция 2 (вопросы разрешены
по поручению владельца). Меню режимов (`add-mode-menu`) уже готово принять этот режим.

## What Changes

- В меню режимов первым появляется режим **«Последовательности»** со своими настройками:
  ключ (скрипичный / басовый / оба), диапазон (позиция / октава / весь стан), последовательностей
  в сессии (счётчик 1–10, по умолчанию 10), нот в шаге (счётчик 1–3, по умолчанию 1),
  «переключать автоматически» (флажок, выключен). Настройки запоминаются.
- В упражнении на стане сразу вся **последовательность из 3–8 шагов** (закрашенные головки без
  штилей, без ритма и тактовых черт). **Текущий шаг** — акцентный цвет и черта под станом.
- **Без таймера.** Верно — шаг «оседает» (зелёный + сплошное кольцо), акцент переходит дальше.
  Мимо — перехода нет, ноты шага дважды пульсируют (при «уменьшить движение» — пунктирная рамка),
  неверные ноты видны полыми красными головками на своей высоте. **«Пропустить»** — приглушённый
  цвет + квадратная рамка.
- После последнего шага — **«Далее»**; с флажком — отсчёт 3 с прямо на кнопке «Далее (3)».
  «Пропустить» и «Далее» стоят на месте «Проверки пианино», число кнопок не меняется.
- **Экран итога** на месте стана: верных с первой попытки / с ошибкой / пропущенных, точность,
  до пяти самых медленных нот со средним временем реакции; «Повторить» (те же последовательности)
  и «Новая».
- В начале каждой последовательности **экранная клавиатура центрируется** на её диапазоне, чтобы
  нужные клавиши были видны и доступны касанием.
- Меню режимов получает черновик настроек на экране режима: «Назад» отбрасывает изменения,
  «Выбрать»/«Старт» подтверждают и сохраняют их.
- План CLAUDE.md §10, этап 4 уточняется ссылкой на C-STF-2 и `add-sequences-mode`.
- **Замечания владельца после первой проверки на планшете:**
  - флажок «Переключать автоматически» дублируется на главный экран — квадрат со значком, без
    подписи; тот же значок у флажка в меню;
  - кнопка «Режим: …» недоступна, пока меню открыто, а касание вне меню закрывает его по
    `click`, чтобы меню не открывалось повторно;
  - **регресс MIDI:** если пианино перехватило другое приложение на планшете, связь числится, а
    ноты не приходят до переподключения кабеля. При возвращении в приложение вход теперь
    переоткрывается, а в «Проверке пианино» есть кнопка «Переподключить пианино».

## Capabilities

### New Capabilities

- `sequences-mode`: режим «Последовательности» — настройки, построение последовательностей,
  реакция на верное и неверное нажатие, пропуск, переход между последовательностями с отсчётом,
  экран итога, центрирование клавиатуры, остановка.

### Modified Capabilities

- `mode-menu`: кнопка режима недоступна, пока меню открыто; касание кнопки режима при открытом
  меню только закрывает его. Остальные требования (список, экран настроек, сохранение
  подтверждённых настроек) этот change реализует для первого режима с настройками, не меняя.
- `midi-input`: переоткрытие активного входа при возвращении в приложение и ручное
  переподключение.

Требования `staff-exercise` («Разминка») не меняются.

## Impact

- Новый код: `src/engine/sequences/` (генератор последовательностей, автомат сессии, подсчёт
  итога), `src/ui/sequences/` (отрисовка последовательности, экран итога, настройки режима),
  `src/ui/controls/` (группа кнопок, счётчик, флажок в стиле приложения).
- Изменяется: `src/engine/modes/*` (режим «Последовательности», черновик настроек в автомате
  меню), `src/storage/settings.ts` (настройки режима, обратно совместимо), `src/ui/App.tsx`,
  `src/ui/WaitingScreen.*` (слот «Проверка пианино / Пропустить / Далее», итог на месте стана),
  `src/ui/modes/ModeMenu.*` (экран настроек), `src/ui/keyboard/Keyboard.tsx` (центрирование по
  запросу), `src/index.css` (затемнённый акцент для нот), CLAUDE.md §10.
- Новых зависимостей нет: VexFlow уже подключён.
