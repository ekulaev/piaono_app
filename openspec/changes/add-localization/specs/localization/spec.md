# Spec Delta

## Purpose

Язык приложения: ученик выбирает язык в верхней панели, приложение само включает язык системы, помнит выбор и показывает английский там, где перевода нет. Источник требований — C-APP-3 «Язык приложения», редакция 4; ссылки на его OB, INV, NFR и LIM указаны в скобках.

## ADDED Requirements

### Requirement: Кнопка языка в панели
На каждом экране верхняя панель MUST показывать кнопку языка справа после кнопки «Прогресс» и перед кнопкой «Настройки»: флаг текущего языка (значок, не эмодзи; английский — британский флаг) и при ширине экрана от 900 px код языка («RU», «EN»), на более узком экране — только флаг. Зона касания MUST быть не меньше 56×56 px; высота панели MUST NOT меняться. (C-APP-3: OB-1, NFR-1; LIM-1, LIM-2)

#### Scenario: Планшет
- **WHEN** приложение открыто на экране 1280×800 на русском языке
- **THEN** в панели после «Прогресса» видна кнопка с флагом России и «RU», затем «Настройки»

#### Scenario: Телефон
- **WHEN** приложение открыто на экране 740×360
- **THEN** у кнопки языка виден только флаг, подпись для диктора («Язык: Русский») есть, высота панели прежняя

### Requirement: Список языков
Нажатие кнопки языка MUST открывать под ней список всех доступных языков: в строке флаг и название языка на нём самом («Русский», «English»), строка не ниже 64 px. Текущий язык MUST отличаться заливкой и отметкой, а не только цветом. Повторное нажатие кнопки, касание вне списка и Esc MUST закрывать список без смены языка. (C-APP-3: OB-2, NFR-1, NFR-2; LIM-2)

#### Scenario: Открыть и закрыть
- **WHEN** ученик нажимает кнопку языка, затем касается пустого места экрана
- **THEN** список открывается с двумя строками («Русский», «English»), текущая отмечена; после касания список закрыт, язык прежний

#### Scenario: Клавиатура
- **WHEN** список открыт и ученик нажимает Esc
- **THEN** список закрывается, фокус возвращается на кнопку языка

### Requirement: Выбор языка применяется сразу
Нажатие на строку списка MUST закрывать список и сразу показывать приложение на выбранном языке без вопросов, подтверждений и перезапуска. Тексты MUST меняться на месте, экран и ход упражнения MUST сохраняться, связь с пианино MUST NOT прерываться, журнал нот MUST NOT очищаться. Смена MUST занимать не больше 0,3 с; если на месте это невозможно, допустим экран загрузки не дольше 1 с. Идущее упражнение MUST NOT останавливаться ни при открытии списка, ни при смене языка. (C-APP-3: OB-3, OB-4, OB-12, INV-1; LIM-3, LIM-4, LIM-6)

#### Scenario: Смена посреди упражнения
- **WHEN** идёт упражнение, ученик открывает список и выбирает «English»
- **THEN** список закрыт, тексты английские, упражнение идёт с того же места, ноты на стане те же

#### Scenario: Нажатие на текущий язык
- **WHEN** ученик нажимает в списке уже выбранный язык
- **THEN** список закрывается, ничего не меняется

#### Scenario: Список над нотным станом
- **WHEN** список языков открыт
- **THEN** ноты на стане видны полностью: список не заходит в зону стана

### Requirement: Язык при первом запуске
Пока ученик ни разу не выбирал язык, приложение MUST включать первый из предпочитаемых языков системы (в порядке системы), который есть среди доступных; региональный вариант («ru-BY», «en-GB») считается своим языком. Если подходящего нет, MUST включаться английский. (C-APP-3: OB-5)

#### Scenario: Система на русском
- **WHEN** на планшете язык системы «ru-RU», приложение запускается впервые
- **THEN** приложение русское, в панели флаг России

#### Scenario: Первый язык системы недоступен
- **WHEN** языки системы по порядку: немецкий, английский (США)
- **THEN** включается English

#### Scenario: Нет совпадений
- **WHEN** язык системы — только японский
- **THEN** включается English

### Requirement: Выбор языка сохраняется
Выбор ученика MUST сохраняться на устройстве и переживать перезапуск (в том числе «Обновить» и сон планшета); он MUST иметь приоритет над языком системы. Сохранённый язык, которого нет среди доступных, MUST считаться отсутствующим без сообщения об ошибке. Настройки, сохранённые до появления языка, MUST читаться без ошибки. (C-APP-3: OB-6, OB-7, NFR-5)

#### Scenario: Выбор переживает перезапуск
- **WHEN** ученик выбрал English на планшете с русской системой и перезапустил приложение
- **THEN** приложение английское

#### Scenario: Старые настройки
- **WHEN** на устройстве настройки без поля языка
- **THEN** они читаются, прочие настройки и прогресс целы, язык определяется по языку системы

#### Scenario: Неизвестный сохранённый язык
- **WHEN** сохранён язык «xx», которого нет в приложении
- **THEN** действует язык системы, ошибки на экране нет

### Requirement: Английский вместо отсутствующего перевода
Если в файле выбранного языка нет какого-то текста, MUST показываться английский текст; остальные тексты MUST оставаться на выбранном языке. Пустых мест, служебных ключей и сообщений об ошибке на экране MUST NOT быть. (C-APP-3: OB-8, INV-3)

#### Scenario: Часть перевода отсутствует
- **WHEN** выбран язык, где нет перевода одной подписи
- **THEN** эта подпись английская, остальные — на выбранном языке

### Requirement: Что переводится
На выбранном языке MUST быть все тексты интерфейса: кнопки, подписи, заголовки, статус связи и «что делать», «Настройки», «Прогресс», меню режимов и названия режимов, тексты подсказок «?» и диалога «Да / Нет», итоги, пустые состояния, подписи для диктора, всплывающие подсказки; числа, десятичный знак, дата и формы числительных («1 попытка / 2 попытки / 5 попыток») MUST следовать правилам языка. Не переводятся буквенные названия нот, ключи, длительности и названия языков в списке. Тексты MUST NOT быть зашиты в экранах вне файлов перевода. (C-APP-3: OB-10, INV-2)

#### Scenario: Прогресс на английском
- **WHEN** выбран English и открыт «Прогресс» с трудным местом «F3, 12 попыток, 58 % чисто, 2,1 с»
- **THEN** строка английская: «12 attempts», «2.1 s»; название ноты «F3» то же

#### Scenario: Склонение по-русски
- **WHEN** выбран русский, попыток 1, 2 и 5
- **THEN** «1 попытка», «2 попытки», «5 попыток»

#### Scenario: Подписи для диктора
- **WHEN** выбран English
- **THEN** подписи для диктора и всплывающие подсказки у кнопок английские

### Requirement: Метаданные страницы
Заголовок вкладки, описание страницы и язык документа MUST быть на языке приложения и MUST меняться вместе с остальными текстами. Статичная страница до запуска приложения MUST быть английской. (C-APP-3: OB-11)

#### Scenario: Заголовок вкладки
- **WHEN** приложение на русском, затем выбран English
- **THEN** заголовок вкладки «Sight-reading Trainer», язык документа `en`

### Requirement: Новый язык добавляется файлом
Каждый язык MUST описываться одним файлом перевода; код языка MUST входить в имя файла. Добавление файла MUST добавлять строку в список языков (флаг и название на самом языке) без правки экранов. Для языка без своего флага MUST показываться его код. (C-APP-3: OB-9, INV-2, NFR-6)

#### Scenario: Добавлен язык
- **WHEN** в приложение добавлен файл перевода нового языка
- **THEN** в списке появляется третья строка; непереведённые тексты английские

### Requirement: Переводы доступны без сети
Все файлы переводов MUST быть доступны после первой загрузки без сети; смена языка без сети MUST работать так же, как с сетью. (C-APP-3: NFR-4)

#### Scenario: Смена языка в авиарежиме
- **WHEN** приложение уже открывалось, планшет в авиарежиме, ученик выбирает «English»
- **THEN** приложение становится английским

### Requirement: Язык не меняет данные
Смена языка MUST NOT менять накопленный прогресс, настройки режимов, выбранное устройство, глиссандо и активный режим; сохранённые данные MUST NOT зависеть от языка. (C-APP-3: INV-1)

#### Scenario: Туда и обратно
- **WHEN** ученик выбирает English, затем «Русский»
- **THEN** статистика, настройки режимов, устройство и глиссандо те же
