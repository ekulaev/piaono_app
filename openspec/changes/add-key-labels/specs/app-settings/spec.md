# Spec Delta

## ADDED Requirements

### Requirement: Настройка «Подписи на клавишах»
Приложение MUST хранить на устройстве одно булево значение «Подписи на клавишах» вместе с остальными настройками (ключ `piaono.settings.v1`). По умолчанию значение MUST быть «выключено». Изменение значения MUST сохраняться сразу, переживать перезапуск приложения и MUST NOT затрагивать остальные настройки и прогресс. Настройки, записанные до появления этого значения, и повреждённое значение MUST читаться как «выключено», без ошибки на экране; остальные настройки при этом MUST сохраняться. Значение MUST быть общим для всех режимов. Переключатель этого значения — флажок в ряду кнопок главного экрана (`key-labels`), в экран «Настройки» он MUST NOT дублироваться. (C-KBD-3: OB-13, OB-14, OB-15)

#### Scenario: Первый запуск
- **WHEN** приложение запущено без сохранённых настроек
- **THEN** подписи на клавишах выключены

#### Scenario: Переживает перезапуск
- **WHEN** ученик включает подписи и перезапускает приложение
- **THEN** подписи включены

#### Scenario: Старая запись
- **WHEN** на устройстве сохранены настройки без этого значения
- **THEN** подписи выключены, остальные настройки и прогресс прежние

#### Scenario: Повреждённое значение
- **WHEN** сохранённое значение не является булевым
- **THEN** подписи выключены, остальные настройки читаются как обычно, ошибки на экране нет
