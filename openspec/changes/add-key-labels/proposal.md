# Proposal

## Why

Чтобы связать место ноты на клавиатуре с её названием и нотой на стане, ученику приходится считать клавиши от «до». Нужна подсказка прямо на клавише, которую можно выключить, когда она уже не нужна. Источник требований — `PSD/specifications/M-KBD/C-KBD-3 Подписи на клавишах.md`, редакция 3, статус `ready`, согласована владельцем (Приложение Б, Р-1…Р-17):
- подписи только на белых клавишах: сверху имя ноты (Do, Re, Mi…), под ним мельче и серым буква с октавой (A1, B6); октава отдельно не пишется;
- флажок «квадрат + значок» — самый правый в ряду кнопок над мини-клавиатурой; значение одно на все режимы, хранится между запусками, по умолчанию выключено;
- подпись нажатой клавиши не опускается вместе с клавишей (иначе она не помещается в низкую зону клавиатуры), а светлеет;
- мини-клавиатура не меняется.

## What Changes

- **Подписи на белых клавишах экранной клавиатуры** — две строки внизу клавиши: имя ноты (крупно, `--ink`, вес 600, не меньше 1.25rem) и буква с октавой (мельче, `--ink-soft`, вес 500, не меньше 1rem). Имена латиницей на любом языке, как в полосе нажатых нот.
- **Нажатая клавиша** — обе строки подписи становятся цвета «бумаги» и остаются на месте, пока клавиша опускается.
- **Флажок подписей** в ряду кнопок главного экрана, правее остальных элементов (в том числе флажка режима): квадрат с отметкой и значок, без текстовой подписи; переключение мгновенное, без перезапуска и остановки упражнения.
- **Настройка «Подписи на клавишах»** — одно булево поле в настройках на устройстве: общее для всех режимов, по умолчанию выключено; старые записи без поля читаются как «выключено».
- Чёрные клавиши и мини-клавиатура не меняются.

## Capabilities

### New Capabilities

- `key-labels`: подписи белых клавиш (состав, вид, нажатое состояние, поведение при прокрутке), флажок подписей в ряду кнопок, область действия значения, граница (чёрные клавиши, мини-клавиатура, язык).

### Modified Capabilities

- `app-settings`: добавляется требование о хранимой настройке «Подписи на клавишах» (значение по умолчанию, сохранение, чтение старых данных). Существующие требования не меняются, поэтому в дельте они не переписываются — добавляется новое.

## Impact

- **Изменяется:**
  - `src/storage/settings.ts` — поле `keyLabels: boolean`, чтение с безопасным значением по умолчанию; тест в `settings.test.ts`;
  - `src/ui/keyboard/Keyboard.tsx`, `Keyboard.css` — свойство `labels`, подпись внутри белой клавиши;
  - `src/ui/WaitingScreen.tsx`, `WaitingScreen.css` — слот флажка в правой колонке ряда кнопок;
  - `src/ui/App.tsx` — состояние флажка из настроек, сохранение, передача в `Keyboard` и `WaitingScreen`;
  - `src/ui/icons/Icons.tsx` — новый линейный значок;
  - `src/i18n/locales/ru.ts`, `en.ts` — название флажка для экранного диктора и подсказки;
  - тест на состав подписей всех 52 белых клавиш (на основе существующего `describeNote`).
- **Совместимость:** ключ `piaono.settings.v1` остаётся прежним; новое поле читается как «выключено», остальные настройки и прогресс не затрагиваются.
- **Связь с `C-APP-5` (компактный экран, не реализован):** там, где экранной клавиатуры нет, флажка тоже нет; при реализации `C-APP-5` флажок скрывается вместе с клавиатурой.
- **Соседний документ:** при реализации убрать «Подписи нот на клавишах» из «Вне Scope» в `C-KBD-1` (Р-17).
- **Новых зависимостей нет.**
