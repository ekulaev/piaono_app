# Spec Delta

## MODIFIED Requirements

### Requirement: Ручное переподключение
Строка «Пианино» экрана «Настройки» MUST показывать кнопку «Переподключить» (≥ 56×56 px) во всех
состояниях, кроме «браузер не умеет MIDI». Нажатие MUST перезапускать приложение (перезагрузка
страницы): Chrome запускает MIDI один раз на страницу, повторный запрос без перезагрузки получает
прежний отказ. Текст последней ошибки запроса доступа, если она была, MUST показываться на экране
«Проверка пианино». (C-APP-1: OB-9, OB-14, Р-4, Р-10)

#### Scenario: Переподключить вручную
- **WHEN** ноты не приходят, и ученик нажал «Переподключить» в «Настройках»
- **THEN** приложение перезапускается и заново запрашивает доступ к MIDI
