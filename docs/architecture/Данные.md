# Данные на устройстве

Всё, что тренажёр помнит об ученике, лежит в `localStorage` планшета под двумя ключами.
Правила совместимости — CLAUDE.md §7: новая версия читает старые данные, битое поле получает
значение по умолчанию, запись одной части не стирает другую, несовместимая смена — только с `.v2`
и миграцией.

| Ключ | Что хранит | Модуль | Как пишется |
|---|---|---|---|
| `piaono.settings.v1` | Выбор ученика: в приложении и в режимах | `storage/settings.ts` | Целиком при каждом изменении (`updateSettings` в `ui/App.tsx`) |
| `piaono.progress.v1` | Накопленное в занятиях: уровни подсказок, статистика | `storage/progress.ts` | Прочитать запись → заменить свою часть → записать |

Обращается к `localStorage` только `storage/browserStorage.ts`. Если браузер не даёт хранилище
(приватный режим, нет места), приложение работает, но ничего не помнит после перезапуска.

## `piaono.settings.v1`

Тип — `Settings` в `storage/settings.ts`. Каждое поле читается отдельно.

| Поле | Что значит | По умолчанию | Спецификация |
|---|---|---|---|
| `glissando` | Скольжение пальцем по клавишам играет ноты | `false` | `C-KBD-1`, `C-APP-1` |
| `preferredInput` | MIDI-вход, выбранный учеником: `{ id, name }` | `null` — выбора не было | `C-MIDI-1`, `C-APP-1` |
| `language` | Язык, выбранный учеником | `null` — язык системы | `C-APP-3` |
| `noteEchoEnabled` | Показывать нажатые ноты | `true` | `C-STF-8` |
| `noteEchoMs` | Время показа карточки: 500–5000 мс, шаг 500 | `1000` | `C-STF-8` |
| `keyLabels` | Подписи нот на белых клавишах | `false` | `C-KBD-3` |
| `keyboardVisible` | Показывать экранную клавиатуру (на компактном экране не действует) | `true` | `C-APP-5` |
| `settingsBarCollapsed` | Бар групп «Настроек» свёрнут до значков | `false` | `C-APP-6` |
| `activeMode` | Режим, который запускает «Старт» | `warmup` | `C-MODE-1` |
| `modeSettings` | Подтверждённые настройки каждого режима — таблица ниже | значения по умолчанию режимов | см. ниже |

### `modeSettings`

Значения по умолчанию и чтение — в модулях `engine/*/settings.ts`: режим приносит свои
настройки сам.

| Режим | Поля | По умолчанию | Модуль | Спецификация |
|---|---|---|---|---|
| `sequences` | `clef` (`treble` / `bass` / `both`), `range` (`position` / `octave` / `staff`), `intervals` (`third` / `fifth` / `octave`), `sequences`, `notesPerStep`, `hints`, `autoAdvance` | скрипичный, позиция, до терции, 10 последовательностей, 1 нота, подсказки вкл., автопереход выкл. | `engine/sequences/settings.ts` | `C-STF-2`, `C-STF-3` |
| `contour` | Те же поля, что у `sequences`; `notesPerStep` и `hints` не используются | как у `sequences` | `engine/sequences/settings.ts` | `C-STF-5` |
| `rhythm` | `level` (1–4), `meter` (3 или 4), `bars` (1 или 2), `patterns` | 1, 4/4, 1 такт, 10 рисунков | `engine/rhythm/settings.ts` | `C-STF-6` |
| `warmup` | `travelSeconds`, `clef`, `trebleRange`, `bassRange` (ступени `{ low, high }`), `tonality`, `naturals`, `autoShift` | 5 с, оба ключа, G3–D6 и B1–F4, `C-major`, без бекаров, без авто-сдвига | `engine/warmup/settings.ts` | `C-STF-9` |
| `intervals` | `variant` (`play` / `name` / `both`), `tasks`, `autoAdvance` | оба варианта, 10 заданий, выкл. | `engine/solfege/intervals/settings.ts` | `C-SOL-2` |
| `durations` | `kinds` (`notes` / `rests` / `both`), `tasks`, `autoAdvance` | ноты и паузы, 10 заданий, выкл. | `engine/solfege/durations/settings.ts` | `C-SOL-3` |

## `piaono.progress.v1`

Тип — `Progress` в `storage/progress.ts`: `{ hints, stats }`. Части читаются независимо:
повреждённые уровни — уровень 3, повреждённый режим статистики — пустой.

### `hints` — уровни подсказок «якорь + интервал»

`{ treble: { level, streak }, bass: { level, streak } }`: уровень 3 → 0 (3 — подсказок больше
всего) и серия удачных последовательностей до следующего уровня. По умолчанию — уровень 3,
серия 0. Модуль — `engine/sequences/hints.ts`; спецификация — `C-STF-3`.

### `stats` — статистика режимов

Запись на каждый режим: `sequences`, `contour`, `rhythm`, `warmup`, `intervals`, `durations`.
Модуль — `engine/stats/stats.ts`; спецификации — `C-STF-4`, для фигур `C-STF-6`, для заданий `C-SOL-1`.

| Таблица режима | Ключ | Пример ключа | Где заполняется |
|---|---|---|---|
| `notes` | ключ и номер MIDI | `treble:60` | «Разминка», «Последовательности» |
| `intervals` | направление и размер | `up3` | «Последовательности», «Контур» |
| `figures` | ритмическая фигура | `eighths` | «Ритм» |
| `tasks` | тип задания сольфеджио | `name:down:TT` | «Интервалы», «Длительности» |

Значение по каждому ключу — счётчики, объём не растёт с числом занятий:

| Поле | Что считает |
|---|---|
| `attempts` | Все законченные попытки |
| `clean` | Верно с первой попытки |
| `errors` | Верно после ошибки |
| `skips` | «Пропустить» или «не успел» |
| `timeCount`, `avgMs` | Сколько времён реакции учтено и их среднее; после 20 каждое новое весит 1/20 |

## Файл резервной копии

`storage/backup.ts` (`C-APP-4`): оба ключа одним файлом JSON.

```json
{
  "app": "piaono",
  "format": 1,
  "createdAt": "2026-10-30T14:05:00+03:00",
  "settings": { "…": "как piaono.settings.v1" },
  "progress": { "…": "как piaono.progress.v1" }
}
```

- Чужой файл отличается по `app`; копия более новой версии формата, чем знает приложение, не
  принимается. Файл больше 1 МБ не читается.
- Дата — время на часах устройства, где сделана копия, без пересчёта часового пояса.
- Содержимое читается так же терпимо, как данные на устройстве. Восстановление пишет прогресс,
  затем настройки; если вторая запись не удалась, прогресс возвращается прежним.

## Как добавить поле

1. Поле и значение по умолчанию — в тип и `DEFAULT_*` модуля (`storage/settings.ts` или
   `engine/*/settings.ts`).
2. Чтение с проверкой: нет поля или неверный тип → значение по умолчанию.
3. Тест на чтение старой записи без этого поля.
4. Строка в таблице этого файла с кодом спецификации.
